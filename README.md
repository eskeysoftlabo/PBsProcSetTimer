# PB's Proc Set Timer 0.2.1

装備しているセットの効果について、**発動した瞬間・発動中・クールダウン**をリアルタイムに表示する ESO アドオンです(コンソール向け)。

**どのセットでも対象です。** ボーナス説明文に「N秒間」「N秒に1回」のような時間が書かれているセットは、自動で行が出ます(時間のない能力値だけのセットは出ません)。

## セットも効果も、アドオンの中に持たない

セットの一覧も、効果の数値も、アビリティIDも入っていません。ゲームから読み取ります。

| 必要なもの | どこから取るか |
|---|---|
| どのセットを何個装備しているか | 装備中アイテムの `GetItemLinkSetInfo`(アイテムのツールチップと同じ呼び出し) |
| 持続時間・クールダウン・発動までの遅延 | セットのボーナス説明文(`GetItemSetBonusInfo`)。「N秒間」「N秒に1回」などの言い回しを、全言語分の手がかり語で判別する(`Parse.lua`) |
| 発動の検出 | 戦闘イベントのアビリティ**名**(下の「照合のしかた」) |
| デバフの実際の残り時間 | `EVENT_EFFECT_CHANGED` の beginTime / endTime |

パッチで数値が変わっても、新しいセットが出ても、説明文が読めれば自動で追従します。

行は、装備数でそのボーナスが有効になっているセットにだけ出ます。時間のあるボーナスが複数あるセットでは、有効になっているうちの一番上のボーナスに従います(例: 3個で3セット効果、5個で5セット効果へ切り替わる)。Perfected セットのボーナスは、ツールチップと同じく Perfected の装備数で数えます。行は最大8つです。

### バーを切り替えたとき

- 効果やクールダウンが**動いている間は、行を消しません。** 切り替えでセットのボーナスが切れても(別のバーの武器が数に入らなくなるなど)、すでに敵に付いている効果と残りのクールダウンは続くので、その分を最後まで表示します。終わった時点で、ボーナスが切れたままなら行が消えます。
- 切り替えの直後に数え直しで一瞬だけ数が落ちることがあっても、**2秒以内に戻れば行は消えません。**
- 切り替えて戻したときは、タイマーを**リセットせず**に続きから数えます。
- ボーナスの行そのものが変わる場合(5個効果から3個効果へ、など)は別の効果なので、新しく始めます。
- 「セットを隠す」(`/procset hide`)は、タイマーが動いていてもすぐ消えます。

## 照合のしかた(どのイベントがどのセットの効果か)

1. **セット名との関係で一致**: アビリティ名がセット名と同じ、セット名の一部、またはセット名を含む(例: 「Martial Knowledge」⊂「Way of Martial Knowledge」)。
2. **説明文に書かれた名前で一致**(効果=バフ/デバフのみ): アビリティ名が説明文にそのまま出てきて、**かつ効果の長さが説明文の秒数と合う**(±0.6秒)。「Major Brutality」のように多くのセットの説明文に出てくる標準バフを、自分のスキルで付いたときに取り違えないための条件です。

外れたときのための手動の逃げ道があります(下のコマンド)。

## 表示

- 緑: 発動中(残り秒数) ／ オレンジ: クールダウン(残り秒数) ／ 水色: 発動可能 ／ 灰色: 効果なし
- 発動した瞬間にバーが白く光ります。
- 効果が付いたあとも続くクールダウンは、同じ行に `発動中 3.2  CD 4.8` のように並びます。

## 位置とサイズ(設定パネルで変更)

- **表示全体**: 位置(左上の角を画面中央から)、大きさ(%)、行の高さ。
- **セット名 / バー / 状態テキスト**の3要素それぞれに、表示する・しない、横位置・縦位置(行の左端と縦中央から)、幅。バーは高さ、文字は大きさ(18〜42)も。
- 「表示のプレビュー」をオンにすると、サンプルの3行(発動中+CD、CD、発動可能)が出るので、見ながら調整できます。

## コマンド `/procset`

| コマンド | 内容 |
|---|---|
| `on` / `off` | 表示のオン・オフ |
| `sets` | 装備中のセットと、それぞれに行があるか(ないならその理由) |
| `hide <ID または名前の一部>` / `show ...` | セットの行を消す・戻す(IDはまだ装備したことがなくても指定可) |
| `status` | 各行の装備数、説明文から読み取った時間、対応づけたアビリティ |
| `log` | 最近の変化(バー切り替え、装備数、ボーナスの有効・無効)。装備数は、装備品から読んだ値とゲームがセットごとに持つ値を並べて出す |
| `text [セットID]` | 装備中のセット(またはIDで指定した1つ)のボーナス説明文の原文と、読み取り結果 |
| `probe` | セット装備中に出た自分のアビリティを一覧表示(対応づけに失敗した効果を探す) |
| `bind <アビリティID> <セットIDまたは名前>` | アビリティを手動でセットに結びつける。`bind clear` で解除 |
| `ignore <アビリティID>` | 取り違えたアビリティを照合の対象から外す。`ignore clear` で解除 |
| `preview` | 位置決め用のサンプル表示 |

設定パネルは LibHarvensAddonSettings(任意)です。そのほか: 戦闘中のみ、発動を検出したセットだけ表示、クールダウン明けの音。

## 0.2.1 での変更

- バーを切り替えると、効果が動いていても行が消えてしまう問題を直しました(上の「バーを切り替えたとき」)。
- `/procset log` を追加しました。

## 0.1.0 からの変更(0.2.0)

- 3セット固定をやめ、装備中の全セットを対象にしました。
- 設定の保存形式を変えたため、0.1.0 の設定(位置など)は初期値に戻ります。

## まだ実機で確かめていないこと

オフラインのモック(`test/`、460項目)で、ロジック・表示・設定パネルを確認しています。PS5 では次が未測定です。

1. **日本語の説明文の言い回し。** 英語版は UESP の文言で確認済みですが、日本語版は読めていません。`/procset text` で読み取り結果を見るのが確実です(`status` の `placed by position` は、手がかり語に当たらず位置で判断した印)。
2. **アビリティ名の対応。** 実際のゲームがどんな名前を付けているかは未測定です。外れていれば `/procset status` の `matched` が空になるので、`/procset probe` で実際の名前を見て、`bind` で結びつけます。全セット対象になったぶん、説明文に標準バフの名前が出るセットでは、まれに自分のスキルのバフを効果と取り違えることがあります。その場合は `ignore` で外せます。
3. **バーを切り替えたときのゲームの数え方。** 切り替えの瞬間に装備数がどう動くか(一瞬落ちるのか、別のバーの武器を数から外すのか)は未測定です。2秒の猶予はその保険です。切り替えてから `/procset log` を実行すると、実際の動きが分かります。
4. **敵のデバフを追える範囲。** `EVENT_EFFECT_CHANGED` が、レティクルやボス以外の敵のデバフについても届くかは未確認です(届かなければ、現在のターゲットの分だけ表示されます)。
